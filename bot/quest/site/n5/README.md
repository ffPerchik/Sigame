# N5 site

Статический сайт для узла N5 «СЧЁТ». Маскируется под обычный сайт архивной компании.
Backend, npm и сборка не нужны.

## Публикация

Опубликовать всю папку `bot/quest/site/n5` как static site.
Для Netlify Drop: перетащить именно папку `n5` на https://app.netlify.com/drop.

## Логика прохождения

1. На обычной странице игрок должен догадаться посмотреть исходник/robots.
2. В служебных полях `index.html`:
   - `operator=argus`
   - наводка на `robots.txt`
   - подсказка искать комментарии в публичных разделах
3. В `services.html` техническая карточка с бинарным регистром → `МОДУЛЬ`.
4. В `contacts.html` meta-поле HEX UTF-8 → `ЛОК`.
5. В `robots.txt` спрятаны `/admin.html` и `/data/ledger.json`.
6. В `data/ledger.json` матрица 7×7 даёт `ЧИСЛО`: числа Фибоначчи после стартовых единиц берутся как адреса по модулю 49 (`2,3,5,8,13`).
7. Вход в `/admin.html`:
   - operator: `argus`
   - password: `МОДУЛЬ-ЧИСЛО-ЛОК`
8. В админке последнее действие: контрольная сумма слов `МОДУЛЬ / ЧИСЛО / ЛОК / ARGUS` → `4623`.
9. Только `4623` вводится в Telegram-бот; промежуточные слова нужны только для сайта.
