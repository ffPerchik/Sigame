# N5 site

Статический сайт для узла N5 «СЧЁТ». Маскируется под обычный сайт архивной компании.
Backend, npm и сборка не нужны.

## Публикация

Опубликовать всю папку `bot/quest/site/n5` как static site.
Для Netlify Drop: перетащить именно папку `n5` на https://app.netlify.com/drop.

## Логика прохождения

1. На обычной странице игрок должен догадаться посмотреть исходник/robots.
2. В комментариях `index.html`:
   - `operator=argus`
   - бинарный регистр → `МОДУЛЬ`
   - HEX UTF-8 → `ЛОК`
3. В `robots.txt` спрятаны `/admin.html` и `/data/ledger.json`.
4. В `data/ledger.json` матрица даёт `ЧИСЛО`: числа Фибоначчи после стартовых единиц берутся как адреса по модулю 9 (`2,3,5,8,13→4`).
5. Вход в `/admin.html`:
   - operator: `argus`
   - password: `МОДУЛЬ-ЧИСЛО-ЛОК`
6. В админке последнее действие: первые четыре адреса Фибоначчи после стартовых единиц до первого модульного переноса → `2358`.
7. Только `2358` вводится в Telegram-бот; промежуточные слова нужны только для сайта.
