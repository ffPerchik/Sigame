# ARG «Аргус-1001» — полные разгадки (ведущий)

Игрокам не отдавать. Порядок узлов любой. После каждого узла бот сам
даёт фрагмент и возвращает в хаб.

Алфавит везде **32 буквы без Ё**:
`АБВГДЕЖЗИЙКЛМНОПРСТУФХЦЧШЩЪЫЬЭЮЯ`  (А=1 … Я=32)

Финальное послание:
**ОТКРОЙ · УСЛЫШЬ · ПРОЧИТАЙ · НАБЛЮДАЙ · ВЫЧИСЛИ · ЗАВЕРШИ**

---

## 0. Вход (SIGame → бот)

1. Пакет `zengame.siq`, финальный вопрос — пейзаж `final_photo.png`.
2. Стеганография LSB этой картинки (или PNG Comment) → текст: переименуй
   `zengame.siq` в `.zip`, распакуй, открой `START.txt`.
3. В `START.txt` два блока Base64. Первый — сообщение Аргуса о дальнейшем доступе,
   второй декодируется в ключ активации **`ARGUS1001`**. Ключ нужно сохранить.
4. Открой бота и нажми обычный `/start` — без ключа.
5. Сначала идёт пролог Жени (Цезарь +1 `РСЙГЖУ`→ПРИВЕТ, A1Z26
   `17-6-18-25-10-12`→ПЕРЧИК, картинка→ZENGAME, Цезарь `ТУБСУ`→СТАРТ,
   морзе `-.. .-`→ДА). Между ними ARGVS лезет в канал (25/50/75/100%),
   Женя пытается чинить.
6. После полного перехвата Аргус пишет `ОСНОВНОЙ ПРОТОКОЛ: LOCKED` и просит ключ
   из контейнера SIGame. Игрок вводит **ARGUS1001** обычным сообщением. Аргус отвечает,
   что игроки не безнадёжны, пишет `UNLOCKED` и открывает хаб.

## N1 · СЛОИ СНИМКА

LSB и цветовые каналы **нет** (это уже вход из SIGame, онлайн-декодеры
наш LSB не читали). Бот шлёт `n1_card.jpg` **документом**, иначе Telegram
сожмёт файл и убьёт EXIF + хвост.

Надпись на кадре рисуешь **ты** на `bot/quest/source/n1_carrier.jpg` (задом наперёд
`ЬТРУНВ ИРТОМС` → СМОТРИ ВНУТРЬ), потом `python bot/tools/make_quest_assets.py`
навешивает EXIF и хвост. Не правь уже готовый `n1_card.jpg` в редакторе —
хвост пропадёт.

### Ответ 1 → `СМОТРИ ВНУТРЬ`

1. Скачай документ, открой как картинку.
2. На экране монитора зелёным: `ЬРТУНВ ИРТОМС` — задом наперёд.
3. В бота: **СМОТРИ ВНУТРЬ**

### Ответ 2 → `255,217` (или `FFD9`)

1. Свойства / exiftool: Author/Artist = `255,217` (это байты FF D9, конец JPEG).
2. В бота: **255,217** или **FFD9**

### Ответ 3 → `СЛОИ`

1. HxD / `strings n1_card.jpg`. После маркера конца JPEG (`FF D9`) дописано
   `secret code: 18-12-15-09`.
2. A1Z26 без Ё: 18=С, 12=Л, 15=О, 09=И.
3. В бота: **СЛОИ**

Фрагмент: **ОТКРОЙ**

## N2 · ЭХО

Все три файла — слои одной аудиопередачи. Результаты первых двух слоёв нужны для
расшифровки третьего.

### Ответ 1 → `КЛЮЧ`

1. Скачай `n2_1.wav`.
2. Audacity → Effect → Reverse.
3. Слышны точки/тире. Русский Морзе:
   К=`-.-`  Л=`.-..`  Ю=`..--`  Ч=`---.`
4. В бота: **КЛЮЧ**. Это одновременно ключ для последующего шифра.

### Ответ 2 → `ФИБО`

1. Скачай `n2_2.wav`.
2. Посчитай короткие импульсы между длинными паузами: `1, 1, 2, 3, 5, 8`.
3. Это начало ряда Фибоначчи — инструкция для финального извлечения.
4. В бота: **ФИБО**.

### Ответ 3 → `ЛЬДА`

1. Скачай `n2_3.wav`: в обычном проигрывателе слышен короткий оригинальный
   вальс, а не шум.
2. Открой спектрограмму с окном не меньше 1024 и смотри диапазон примерно 4–10 кГц.
   Четыре строки складываются в:
   `ВИЖЕНЕР ЬЧЮШЁХ ЖДЪЯЙУЬ ОЮИШРР ЕЩ ЩМОШЪЗ ФЯФО ЬДР ЮВХЯОЧЭЩМ МЫЛЛАЭ РБЁ ЪЪВ ИЦЪГД ЦЗВЧ`.
3. Первая строка задаёт шифр. Остальное расшифруй Виженером, ключ — **КЛЮЧ**.
   Используется обычный полный алфавит `АБВГДЕЁЖЗИЙКЛМНОПРСТУФХЦЧШЩЪЫЬЭЮЯ`:
   33 буквы с Ё, `А=0`; пробелы не двигают и не сбрасывают ключ.
   Проверка первых блоков: `ЬЧЮШЁХ ЖДЪЯЙУЬ` → `СЛАБЫЙ ИМПУЛЬС`.
4. Открытый текст:
   `СЛАБЫЙ ИМПУЛЬС ГАСНЕТ НО НОЧНОЙ ЭФИР ЕЩЕ АККУРАТНО ХРАНИТ ЕГО ПОД СЛОЕМ ЛЬДА`.
5. Последнее слово в бота: **ЛЬДА**.

### Ответ 4 → `СИГНАЛ`

1. Пронумеруй слова открытого текста.
2. Возьми позиции Фибоначчи без повторной единицы: `1, 2, 3, 5, 8, 13`.
3. Первые буквы этих слов: С И Г Н А Л.
4. В бота: **СИГНАЛ**.

Фрагмент: **УСЛЫШЬ**
