# ARG «Аргус-1001» — полные разгадки (ведущий)

Игрокам не отдавать. Порядок узлов любой. После каждого узла бот сам
даёт фрагмент и возвращает в хаб.

Алфавит везде **32 буквы без Ё**:
`АБВГДЕЖЗИЙКЛМНОПРСТУФХЦЧШЩЪЫЬЭЮЯ`  (А=1 … Я=32)

Финальное послание:
**ОТКРОЙ · УСЛЫШЬ · ПРОЧИТАЙ · НАБЛЮДАЙ · ВЫЧИСЛИ · ЗАВЕРШИ**

---

## 0. Вход (SIGame → бот)

1. Пакет `zengame.siq`, финальный вопрос — пейзаж `final_photo.png`.
2. Стеганография LSB этой картинки (или PNG Comment) → текст: переименуй
   `zengame.siq` в `.zip`, распакуй, открой `START.txt`.
3. В `START.txt` два блока Base64. Первый — сообщение Аргуса о дальнейшем доступе,
   второй декодируется в ключ активации **`ARGUS1001`**. Ключ нужно сохранить.
4. Открой бота и нажми обычный `/start` — без ключа.
5. Сначала идёт пролог Жени (Цезарь +1 `РСЙГЖУ`→ПРИВЕТ, A1Z26
   `17-6-18-25-10-12`→ПЕРЧИК, картинка→ZENGAME, Цезарь `ТУБСУ`→СТАРТ,
   морзе `-.. .-`→ДА). Между ними ARGVS лезет в канал (25/50/75/100%),
   Женя пытается чинить.
6. После полного перехвата Аргус пишет `ОСНОВНОЙ ПРОТОКОЛ: LOCKED` и просит ключ
   из контейнера SIGame. Игрок вводит **ARGUS1001** обычным сообщением. Аргус отвечает,
   что игроки не безнадёжны, пишет `UNLOCKED` и открывает хаб.

## N1 · СЛОИ СНИМКА

LSB и цветовые каналы **нет** (это уже вход из SIGame, онлайн-декодеры
наш LSB не читали). Бот шлёт `n1_card.jpg` **документом**, иначе Telegram
сожмёт файл и убьёт EXIF + хвост.

Надпись на кадре рисуешь **ты** на `bot/quest/source/n1_carrier.jpg` (задом наперёд
`ЬТРУНВ ИРТОМС` → СМОТРИ ВНУТРЬ), потом `python bot/tools/make_quest_assets.py`
навешивает EXIF и хвост. Не правь уже готовый `n1_card.jpg` в редакторе —
хвост пропадёт.

### Ответ 1 → `СМОТРИ ВНУТРЬ`

1. Скачай документ, открой как картинку.
2. На экране монитора зелёным: `ЬРТУНВ ИРТОМС` — задом наперёд.
3. В бота: **СМОТРИ ВНУТРЬ**

### Ответ 2 → `255,217` (или `FFD9`)

1. Свойства / exiftool: Author/Artist = `255,217` (это байты FF D9, конец JPEG).
2. В бота: **255,217** или **FFD9**

### Ответ 3 → `СЛОИ`

1. HxD / `strings n1_card.jpg`. После маркера конца JPEG (`FF D9`) дописано
   `secret code: 18-12-15-09`.
2. A1Z26 без Ё: 18=С, 12=Л, 15=О, 09=И.
3. В бота: **СЛОИ**

Фрагмент: **ОТКРОЙ**

## N2 · ЭХО

Все три файла — слои одной аудиопередачи. Результаты первых двух слоёв нужны для
расшифровки третьего.

### Ответ 1 → `КЛЮЧ`

1. Скачай `n2_1.wav`.
2. Audacity → Effect → Reverse.
3. Слышны точки/тире. Русский Морзе:
   К=`-.-`  Л=`.-..`  Ю=`..--`  Ч=`---.`
4. В бота: **КЛЮЧ**. Это одновременно ключ для последующего шифра.

### Ответ 2 → `ФИБО`

1. Скачай `n2_2.wav`: он звучит как шесть нажатий телефонных клавиш.
2. Это DTMF. Декодер телефонных тонов даёт `1, 1, 2, 3, 5, 8`.
3. Получается начало ряда Фибоначчи — инструкция для финального извлечения.
4. В бота: **ФИБО**.

### Ответ 3 → `ЛЬДА`

1. Скачай `n2_3.wav`: в обычном проигрывателе слышен короткий оригинальный
   вальс, а не шум.
2. Открой спектрограмму с окном не меньше 1024 и смотри диапазон примерно 4–10 кГц.
   Четыре строки складываются в:
   `ВИЖЕНЕР ЬЧЮШЁХ ЖДЪЯЙУЬ ОЮИШРР ЕЩ ЩМОШЪЗ ФЯФО ЬДР ЮВХЯОЧЭЩМ МЫЛЛАЭ РБЁ ЪЪВ ИЦЪГД ЦЗВЧ`.
3. Первая строка задаёт шифр. Остальное расшифруй Виженером, ключ — **КЛЮЧ**.
   Используется обычный полный алфавит `АБВГДЕЁЖЗИЙКЛМНОПРСТУФХЦЧШЩЪЫЬЭЮЯ`:
   33 буквы с Ё, `А=0`; пробелы не двигают и не сбрасывают ключ.
   Проверка первых блоков: `ЬЧЮШЁХ ЖДЪЯЙУЬ` → `СЛАБЫЙ ИМПУЛЬС`.
4. Открытый текст:
   `СЛАБЫЙ ИМПУЛЬС ГАСНЕТ НО НОЧНОЙ ЭФИР ЕЩЕ АККУРАТНО ХРАНИТ ЕГО ПОД СЛОЕМ ЛЬДА`.
5. Последнее слово в бота: **ЛЬДА**.

### Ответ 4 → `СИГНАЛ`

1. Пронумеруй слова открытого текста.
2. Возьми позиции Фибоначчи без повторной единицы: `1, 2, 3, 5, 8, 13`.
3. Первые буквы этих слов: С И Г Н А Л.
4. В бота: **СИГНАЛ**.

Фрагмент: **УСЛЫШЬ**

## N3 · ТЕТРАДЬ

### Ответ 1 → `РЕШЕТКА`

Лист I, масонский / pigpen. Автор объявляет о новом языке и показывает, как
на нём записывается **СИКССЕВЕН**. Снизу показаны квадратная решётка с буквами
**А–И** и частично сгоревшая ромбическая с буквами **Т–Ъ**. Обе — открытые сетки
3×3 без внешней обводки; сначала используются знаки без точки, затем с точкой.
Послание из семи знаков нарисовано единой строкой и целиком
повёрнуто на 45°.
В бота: **РЕШЕТКА**

### Ответ 2 → `ПОЛИБИЙ`

Лист II, длинная фраза на трёх рельсах (rail fence). На листе рельсы уже
разделены по длинам 7 + 14 + 7:

```text
СУЙРИЯИ
ЛДЮИШФНСТМПЛБЯ
ЕЩИОИОИ
```

Чтение зигзагом вниз-вверх даёт:
`СЛЕДУЮЩИЙ ШИФР НОСИТ ИМЯ ПОЛИБИЯ`.
В бота: **ПОЛИБИЙ**

### Ответ 3 → `СТРОФА`

Лист III. Квадрат Полибия 6×6, алфавит из 33 русских букв с Ё. Пометка о первом
слове повёрнута вертикально вдоль левого поля; в таблице уже стоят контрольные
буквы `Ё` и `Я`. Ключевое слово **РЕШЕТКА** ставится в начало без повторов,
затем дописывается остальной алфавит:

```text
Р Е Ш Т К А
Б В Г Д Ё Ж
З И Й Л М Н
О П С У Ф Х
Ц Ч Щ Ъ Ы Ь
Э Ю Я
```

Пары `43 14 11 41 45 16` читаются как строка, затем столбец и дают **СТРОФА**.
В бота: **СТРОФА**

### Ответ 4 → `ИСТИНА`

Лист IV механически требует все три предыдущих ответа:

1. **РЕШЕТКА** — представить строфу как решётку 6×6: шесть строк по шесть слов.
2. **ПОЛИБИЙ** — читать пары как координаты `строка.столбец`.
3. **СТРОФА** — использовать именно пары, которыми это слово было записано на
   листе III: `43 14 11 41 45 16`.

На листе IV новых координат нет: шесть старых пар переносятся в новую строфу.
После выбора клетки берётся первая буква находящегося в ней слова:

| коорд | слово  | буква |
| ----- | ------ | ----- |
| `43`  | ищет   | И |
| `14`  | свет   | С |
| `11`  | Тихий  | Т |
| `41`  | Иней   | И |
| `45`  | ночной | Н |
| `16`  | архив  | А |

Получается **ИСТИНА**. В бота: **ИСТИНА**.

Фрагмент: **ПРОЧИТАЙ**

## N5 · СЧЁТ

На стороне бота у N5 один ввод: финальный код **6535**.
Вся последовательность живёт на сайте. Внешне это обычная многостраничная
витрина архивной компании, внутри — расчётный контур. Netlify публикует
`bot/quest/site/n5`. Текущая ссылка: `https://argus1001.netlify.app/`.

### Сайт: стартовая разведка

1. Открыть главную страницу и посмотреть исходный код.
2. В комментариях есть короткие служебные следы:
   - `/robots.txt`;
   - `operator=argus`.

### Контрольное слово 1 → `МОДУЛЬ`

1. Проверить исходники публичных страниц.
2. В `/services.html` есть комментарий только с битами:
   `001101 001111 000101 010100 001100 011101`.
3. По общей логике узла это 6-битные номера букв, `А=000001`, алфавит без Ё.
4. Получается **МОДУЛЬ**. Это первая часть пароля, в бот её вводить не нужно.

### Контрольное слово 2 → `ЧИСЛО`

1. Открыть `/robots.txt`. Там указаны `/admin.html` и `/data/ledger.json`.
2. Открыть `/data/ledger.json`. Там матрица 7×7 с 49 адресами и много шумовых букв.
3. Правило реестра: взять числа Фибоначчи после стартовых единиц и применять модуль 49.
   Первые адреса: `2, 3, 5, 8, 13, 21, 34, 55 mod 49 = 6...`.
4. Для пяти букв берём адреса `2 3 5 8 13`. В матрице они дают Ч И С Л О → **ЧИСЛО**.
   Это вторая часть пароля.

### Контрольное слово 3 → `ЛОК`

1. Проверить исходники публичных страниц.
2. В `/contacts.html` есть комментарий только с байтами: `d0bb d0be d0ba`.
3. Декодирование как UTF-8 hex даёт **ЛОК**. Это третья часть пароля.

### Админка и финальный код `6535`

1. Открыть `/admin` или `/admin.html`.
2. Вход:
   - operator: `argus`
   - password: `МОДУЛЬ-ЧИСЛО-ЛОК`
3. Админка показывает четыре слова в верном порядке:
   **МОДУЛЬ / ЧИСЛО / ЛОК / ARGUS**.
4. Видимый текст: «Слова уже приняли верные позиции, вот только на панели кодовый замок».
5. Посмотреть код элемента панели замка. На `.lock-panel` есть атрибут:
   `data-rule="код принимает длины слов"`.
6. Берём длины слов в показанном порядке:
   - `МОДУЛЬ` → 6
   - `ЧИСЛО` → 5
   - `ЛОК` → 3
   - `ARGUS` → 5
7. Финальный код: **6535**. Именно его игрок вводит в Telegram-бот.

Фрагмент: **ВЫЧИСЛИ**

## Тебе как ведущему
