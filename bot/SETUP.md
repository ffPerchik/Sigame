# Как запустить бота — с нуля, по шагам (Windows)

Бот работает на твоём компьютере: пока запущено окно с ним — квест идёт.
Нужно ~10 минут. Делай по порядку.

---

## Шаг 1. Проверь, что есть Python
Открой **PowerShell** (Пуск → напиши «PowerShell») и введи:
```powershell
python --version
```
- Выдало `Python 3.10` или новее — отлично, иди к шагу 2.
- «python не распознано» → скачай установщик с https://python.org , запусти и
  **ОБЯЗАТЕЛЬНО поставь галочку «Add Python to PATH»** в самом низу окна установки.
  После установки закрой и снова открой PowerShell, проверь ещё раз.

## Шаг 2. Создай бота в Telegram (получи токен)
1. Открой в Телеге **@BotFather** → нажми Start.
2. Отправь команду `/newbot`.
3. Придумай **имя** (любое, напр. `Quest Bot`).
4. Придумай **username** — уникальный, должен кончаться на `bot`
   (напр. `vasya_quest_bot`). Это «адрес» бота.
5. BotFather пришлёт сообщение с **токеном** вида
   `123456789:AAH...long_string` → **скопируй его** и сохрани куда-нибудь.

## Шаг 3. Узнай свой Telegram ID (ты — ведущий)
Открой **@userinfobot** → нажми Start. Он пришлёт твой `Id: 123456789`.
Запиши это число — это `HOST_ID`.

## Шаг 4. Забери свежий код с репозитория
В PowerShell:
```powershell
cd C:\Users\User\Sigame
git pull
cd bot
```
(Если ругается на `git pull` — напиши `git pull origin arena/019ff230-sigame`.)
Теперь ты в папке `bot` с файлами бота.

## Шаг 5. Установи библиотеки (один раз)
```powershell
pip install -r requirements.txt
```
Побегут строчки установки. Дождись окончания. (Если пишет «pip не найден» —
введи `python -m pip install -r requirements.txt`.)

> Хочешь чисто — можно в виртуальном окружении:
> `python -m venv .venv`, затем `.venv\Scripts\activate`, потом `pip install ...`.
> Если активация ругается на «выполнение сценариев отключено» — в PowerShell от
> администратора: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`. Но это
> необязательно — можно ставить и просто в систему.

## Шаг 6. Настрой `.env`
```powershell
copy .env.example .env
notepad .env
```
Откроется блокнот. Впиши свои значения (остальное не трогай):
```ini
BOT_TOKEN=сюда_вставь_токен_от_BotFather
HOST_ID=сюда_свой_id_из_шага_3
ENTRY_CODE=ZENGAME2026
BOT_USERNAME=vasya_quest_bot
```
- `BOT_TOKEN` — из шага 2.
- `HOST_ID` — из шага 3.
- `ENTRY_CODE` — код старта квеста (по умолчанию `ZENGAME2026`). Его игроки
  будут присылать боту: `/start ZENGAME2026`.
- `BOT_USERNAME` — твой username из шага 2 **без @**.

Сохрани (`Ctrl+S`) и закрой блокнот.

## Шаг 7. Запусти бота
```powershell
python bot.py
```
Увидишь в консоли:
```
Бот @vasya_quest_bot запущен. HOST_ID=... Жду игроков.
```
🎉 Бот жив. **Не закрывай это окно PowerShell**, пока идёт квест.

## Шаг 8. Проверь, что работает
1. В Телеге найди своего бота по username (например `@vasya_quest_bot`) → открой → `/start`.
2. Бот попросит код → отправь ему: `/start ZENGAME2026`
3. Должно приехать приветствие квеста и первый шифр. Значит — всё ок.
4. Команды ведущего (тебе, в том же чате с ботом): `/help`, `/stats`, `/pending`.

---

## Как остановить
В окне с ботом нажми `Ctrl+C`.

## Важно про «неделю»
Бот работает, **пока открыто окно с `python bot.py`**. Заснул/выключился ПК — бот встал.
- На время игры просто держи ПК включённым: Параметры → Система → Питание →
  запрети «сон» от сети. Или закрой крышку ноута так, чтоб он не уснул.
- Если игроки растянут квест на неделю и тебе нужен честный 24/7 без твоего ПК —
  тогда поднимаем на дешёвом сервере (VPS ~$3–5/мес, Linux). Для начала своего ПК хватит.

## Частые проблемы
| Симптом | Что делать |
|---|---|
| `python`/`pip` не найдены | Переустанови Python с галочкой «Add to PATH», перезапусти PowerShell. |
| Бот не отвечает в Телеге | Проверь, что окно `python bot.py` открыто и не выдаёт ошибку; проверь `BOT_TOKEN`. |
| `Unauthorized` / `Conflict` | Неверно скопирован токен или бот уже запущен в другом окне. |
| Игрок пишет `/start код`, а бот молчит | Код не совпадает с `ENTRY_CODE` в `.env`. |
