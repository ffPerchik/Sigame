# Своя игра для друзей

Пакет для SIGame / «Своей игры» на троих (каждый сам за себя). После основной
игры планируется старт индивидуального ARG-квеста в стиле Cicada 3301.

## Что здесь

| Путь | Что это |
| --- | --- |
| `Своя игра для друзей.siq` | **Готовый пакет** — открывайте в SIGame / SIOnline. |
| `content/package.yaml` | Исходник пакета (людино-читаемый): раунды, темы, вопросы. |
| `content/Images/` | Картинки тем (Armenian food, BTS). |
| `content/DRAFT_TEMPLATE.yaml` | Шаблон для ваших тем (география и т.д.). |
| `tools/build_package.py` | Сборщик `.siq` из `package.yaml`. |
| `tools/ygpackage3.1.xsd` | Схема формата (для проверки `--validate`). |
| `Zengame.siq`, `Вопросы SIGame.siq` | Сторонние пакеты (Git LFS), просто лежат для примера. |

## Как пересобрать пакет

```bash
pip install pyyaml            # и опционально xmlschema, Pillow
python3 tools/build_package.py --validate
```

На выходе — `Своя игра для друзей.siq` в корне репозитория.

## Как добавить свои темы

1. Откройте `content/package.yaml` (или `content/DRAFT_TEMPLATE.yaml` как опору).
2. Добавьте раунд/тему/вопросы. Картинки кладите в `content/Images/` и
   ссылайтесь по имени (`image: file.jpg`).
3. Пересоберите: `python3 tools/build_package.py --validate`.

Формат тем нестрогий — у каждой темы может быть своё число вопросов.

## Примечание про формат `.siq`

`.siq` — это ZIP с `content.xml` (формат v4, неймспейс `ygpackage3.0.xsd`) и
папками `Images/`, `Audio/`, `Video/`. Сборщик кладёт `content.xml` и копию
`[Content].xml` для совместимости со старыми версиями читалки. Сгенерированный
пакет коммитится в Git как обычный файл (Git LFS в среде сборки недоступен);
большие сторонние `.siq` по-прежнему хранятся через LFS.
