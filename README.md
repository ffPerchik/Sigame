# Своя игра для друзей

Пакет для SIGame / «Своей игры» на троих (каждый сам за себя). После основной
игры планируется индивидуальный ARG-квест в стиле Cicada 3301.

## Готовый пакет

**`Своя игра для друзей.siq`** — финальный пакет (формат SIGame **v5**). Открывай
в SIGame / SIOnline.

Собран из заготовки игрока (`Zengame.siq`, 27 тем) + две темы от агента:
**«Армянская еда»** (узнай блюдо по фото) и **BTS (1 фото = 1 участник)**.

### Структура (5 раундов, 211 вопросов)

| Раунд | Тем | Вопросов | Содержание |
| --- | --- | --- | --- |
| 1 — География *(тематический)* | 6 | 45 | Столицы, Анаграммы городов, Страна по президенту, Флаги, Из какой страны?, Валюта |
| 2 — Кино, мультики, мемы | 6 | 40 | Кинчик, Картинка с фразой, Мультики, Шрек, Всё о мультиках, Хреново нарисовали мем |
| 3 — Музыка и стиль | 5 | 40 | Продолжи песню, Shazam 2025, Женский косплей, Вторая половинка, Средневековые афиши |
| 4 — Игры и головоломки | 6 | 45 | Майнкрафт, Еноты, Внимательность, 50/50, Античность, Рандом |
| 5 — Микс + бонус | 6 | 41 | Случайные + **Армянская еда** + **BTS** |

Раунд 1 — полностью тематический (география), как просили друзья. Все спецтипы
вопросов заготовки (кот в мешке, без риска, для всех, ва-банк, выбор ответа)
сохранены — темы перенесены целиком.

## Сборка

```bash
python3 tools/build_v5.py
```

`build_v5.py` читает `Zengame.siq` (content.xml + медиа прямо из ZIP),
перераспределяет темы по раундам, добавляет «Армянскую еду» и «BTS»
(картинки из `content/Images/`), регенерирует манифест и собирает
`Своя игра для друзей.siq`.

Чтобы поменять состав раундов — отредактируйте `ROUND_PLAN` в
`tools/build_v5.py` (индексы тем — по порядку в `Zengame.siq`) и пересоберите.

## Примечание

`.siq` — это ZIP с `content.xml` (v5) и папками `Images/`, `Audio/`, `Video/`.
Кириллические имена медиа хранятся URI-закодированными — это нормально для формата.
`.gitattributes` помечает `*.siq` как бинарник (`-text`), чтобы git не портил ZIP.
