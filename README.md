# Zengame

Пакет для SIGame / «Своей игры» на троих (каждый сам за себя) + спрятанный старт
ARG-квеста в стиле Cicada 3301.

## Файлы

| Файл | Что это |
| --- | --- |
| **`zengame.siq`** | Готовый пакет (формат SIGame v5). Открывай в SIGame / SIOnline. |
| `source.siq` | Исходная заготовка (27 тем + медиа) — источник для сборки. |
| `tools/build_v5.py` | Сборщик `zengame.siq` из `source.siq`. |
| `tools/make_stego_image.py` | Стеганография: прячет послание в `content/Images/final_photo.png`. |
| `content/Images/` | Картинки тем (Армянская еда, BTS) + `final_photo.png` (стегано). |
| `content/stego_carrier.jpg` | Носитель для стегано (обычный пейзаж). |

5 раундов + финал, 30 тем. Все темы вида `<смайлик><название>`, смайлики уникальны.

## Сборка

```bash
python3 tools/make_stego_image.py    # (пере)создать стегано-картинку
python3 tools/build_v5.py            # собрать zengame.siq
```

Состав раундов и переименование тем — `ROUND_PLAN` и `RENAME` в `tools/build_v5.py`.

## Квест: как найти старт

1. В **Финале** показывают обычный пейзаж (`final_photo.png`). Вопрос учит слову
   **«стеганография»** — намёк, что внутри картинки что-то спрятано.
2. Извлеки младшие биты (LSB) этой картинки → послание:
   *«переименуй zengame.siq в .zip, распакуй и открой START.txt»*.
3. `zengame.siq` — это ZIP. Переименуй в `.zip`, распакуй, открой **`START.txt`**.
4. В `START.txt` — сообщение под Base64 → начало индивидуального квеста.

`tools/make_stego_image.py --decode` читает спрятанное сообщение обратно (проверка).

## Ачивки SIGame → подсказки квеста

Настольная SIGame сохраняет HTML-журнал с ответами и изменениями счёта. После игры
скрипт автоматически считает ачивки и формирует команды `/addhint` для бота:

```bash
python tools/sigame_achievements.py path/to/game_log.html --map players.json
```

Список ачивок, настройка журналов и формат `players.json` —
[`doc/SIGAME_ACHIEVEMENTS.md`](doc/SIGAME_ACHIEVEMENTS.md).

## Примечание

`.siq` — ZIP с `content.xml` (v5) и папками `Images/`, `Audio/`, `Video/`.
Кириллические имена медиа хранятся URI-закодированными (норма формата).
`.gitattributes` помечает `*.siq` как бинарник (`-text`), чтобы git не портил ZIP.
