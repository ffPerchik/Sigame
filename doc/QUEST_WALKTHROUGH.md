# ARG «Аргус-1001» — полные разгадки (ведущий)

Игрокам не отдавать. Порядок узлов любой. После каждого узла бот сам
даёт фрагмент и возвращает в хаб.

Алфавит везде **32 буквы без Ё**:
`АБВГДЕЖЗИЙКЛМНОПРСТУФХЦЧШЩЪЫЬЭЮЯ`  (А=1 … Я=32)

Финальное послание:
**ОТКРОЙ · УСЛЫШЬ · ПРОЧИТАЙ · НАБЛЮДАЙ · ВЫЧИСЛИ · ЗАВЕРШИ**

---

## 0. Вход (SIGame → бот)

1. Пакет `zengame.siq`, финальный вопрос — пейзаж `final_photo.png`.
2. Стеганография LSB этой картинки (или PNG Comment) → текст: переименуй
   `zengame.siq` в `.zip`, распакуй, открой `START.txt`.
3. В `START.txt` два блока Base64. Второй декодируется в **`ARGUS1001`**.
4. Боту: `/start ARGUS1001`.
5. Без `HOST_CONSOLE`: ты жмёшь «Запустить». С `HOST_CONSOLE=1` гейт открывается сам.
6. Хаб, кнопки N1…N6.

---

## N1 · СЛОИ СНИМКА

LSB и цветовые каналы **нет** (это уже вход из SIGame, онлайн-декодеры
наш LSB не читали). Бот шлёт `n1_card.jpg` **документом**, иначе Telegram
сожмёт файл и убьёт EXIF + хвост.

Надпись на кадре рисуешь **ты** на `content/n1_carrier.jpg` (задом наперёд
`ЬТРУНВ ИРТОМС` → СМОТРИ ВНУТРЬ), потом `python tools/make_quest_assets.py`
навешивает EXIF и хвост. Не правь уже готовый `n1_card.jpg` в редакторе —
хвост пропадёт.

### Ответ 1 → `СМОТРИ ВНУТРЬ`

1. Скачай документ, открой как картинку.
2. Найди спрятанную надпись, прочитай задом наперёд.
3. В бота: **СМОТРИ ВНУТРЬ**

### Ответ 2 → `255,217` (или `FFD9`)

1. Свойства / exiftool: Author/Artist = `255,217` (это байты FF D9, конец JPEG).
2. В бота: **255,217** или **FFD9**

### Ответ 3 → `СЛОИ`

1. HxD / `strings n1_card.jpg`. После маркера конца JPEG (`FF D9`) дописано
   `18-12-15-09`.
2. A1Z26 без Ё: 18=С, 12=Л, 15=О, 09=И.
3. В бота: **СЛОИ**

Фрагмент: **ОТКРОЙ**

## N2 · ЭХО

### Ответ 1 → `КЛЮЧ`

1. Скачай `n2_reversed.wav`.
2. Audacity → Effect → Reverse.
3. Слышны точки/тире (не речь). Русский Морзе:
   К=`-.-`  Л=`.-..`  Ю=`..--`  Ч=`---.`
4. В бота: **КЛЮЧ**

### Ответ 2 → `ФИБО`

1. Скачай `n2_spec.wav`.
2. Спектрограмма (Audacity, Window size ≥ 1024; или Spek).
3. Слева направо читается слово **ФИБО**.
4. В бота: **ФИБО**

### Ответ 3 → `ЭХО`

1. Картинка журнала, 8 слов:
   `ЭТОТ ХРУПКИЙ ОТКЛИК ПРЯЧЕТСЯ ОСОБО ТИХО СРЕДИ ШУМА`
2. Шапка `1-1-2-3-5-8` — ряд Фибоначчи. Нужны **первые три ненулевых**: 1, 2, 3.
3. Первые буквы слов 1–3: Э Х О.
4. В бота: **ЭХО**
   (слова 5 и 8 — ложный след.)

Фрагмент: **УСЛЫШЬ**

## N3 · ТЕТРАДЬ

### Ответ 1 → `РЕШЕТКА`

Лист I, масонский / pigpen. Семь знаков. Образец А Б В внизу листа.
В бота: **РЕШЕТКА**

### Ответ 2 → `ВИЖНЕР`

Лист II, шифр `ВЕИНРЖ`, 3 рельса (rail fence).

Длины рельсов для 6 букв: 2 + 3 + 1.

```
В . Е
Е И Н
Р . Ж
```

Зигзаг вниз-вверх даёт **ВИЖНЕР**.
В бота: **ВИЖНЕР**

### Ответ 3 → `СТРОФА`

Лист III. Виженер, ключ = **РЕШЕТКА**, шифр `БЧИУЖК`, алфавит 32 без Ё.
На каждом шаге: позиция_шифра − позиция_ключа (по модулю 32).
В бота: **СТРОФА**

### Ответ 4 → `ИСТИНА`

Лист IV. Координаты `1.2  2.3  3.3  4.2  5.3  6.2` = строка.слово,
берётся **первая буква**:

| коорд | слово   | буква |
| ----- | ------- | ----- |
| 1.2   | иней    | И     |
| 2.3   | свет    | С     |
| 3.3   | тишина  | Т     |
| 4.2   | иней    | И     |
| 5.3   | ночи    | Н     |
| 6.2   | архив   | А     |

В бота: **ИСТИНА**

Фрагмент: **ПРОЧИТАЙ**

## Тебе как ведущему

- Подсказки игроку: `/addhint @nick n`, он жмёт `/hint`.
- Застрял: `/setstage <id> <stage_id>` (например `N3_vig`).
- Сброс: `/reset <id>`.
- Соло-тест: `HOST_CONSOLE=1` в `.env` — письма ведущему в консоль, гейт сам.
